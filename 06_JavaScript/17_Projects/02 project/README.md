# Website Development Assignment: Personal Portfolio

## Assignment Overview
Create a responsive personal portfolio website using HTML, CSS, and JavaScript. This project will demonstrate your understanding of web development fundamentals, responsive design principles, and interactive user interfaces.

## Project Topic: Personal Portfolio Website

### Objective
Build a professional personal portfolio website that showcases your skills, projects, and experience. The website should be visually appealing, fully responsive, and interactive.

## Technical Requirements

### 1. HTML Structure (index.html)
- **Semantic HTML5 elements** (header, nav, main, section, article, footer)
- **Proper document structure** with DOCTYPE, html, head, and body tags
- **Meta tags** for responsive design and SEO
- **Navigation menu** with smooth scrolling to sections
- **Contact form** with proper form validation attributes
- **Accessibility features** (alt attributes, proper heading hierarchy)

### 2. CSS Styling (styles.css)
- **Responsive design** using CSS Grid and Flexbox
- **Mobile-first approach** with media queries
- **CSS variables** for consistent theming
- **Smooth animations and transitions**
- **Modern design principles** (typography, color schemes, spacing)
- **Cross-browser compatibility**

### 3. JavaScript Functionality (script.js)
- **Form validation** with custom error messages
- **Smooth scrolling navigation**
- **Interactive animations** (scroll-triggered animations)
- **Dynamic content loading**
- **Mobile menu toggle functionality**
- **Theme switcher** (light/dark mode)
- **Contact form submission handling**

## Specific Features to Implement

### HTML Features
1. **Semantic structure** with proper heading hierarchy (h1, h2, h3)
2. **Form elements** with labels, placeholders, and validation attributes
3. **Image optimization** with proper alt text and responsive images
4. **Meta tags** for SEO and social media sharing
5. **Favicon** implementation

### CSS Features
1. **CSS Grid** for layout structure
2. **Flexbox** for component alignment
3. **CSS animations** and keyframes
4. **Responsive typography** using clamp() and rem units
5. **CSS variables** for theme consistency
6. **Pseudo-elements** for decorative effects
7. **Media queries** for tablet and mobile responsiveness

### JavaScript Features
1. **Event listeners** for user interactions
2. **Form validation** with real-time feedback
3. **Smooth scrolling** to sections
4. **Intersection Observer** for scroll animations
5. **Theme toggle** functionality
6. **Mobile menu** hamburger implementation
7. **Project filtering** system
8. **Loading animations** and preloaders
