# Creating Your First React App

Follow these steps to create your first React application:

## 1. Install Node.js

Download and install Node.js from [nodejs.org](https://nodejs.org/).

## 2. Create a New React App

Open your terminal or command prompt and run:

```bash
npx create-react-app my-first-app
```

Replace `my-first-app` with your desired project name.

## 3. Navigate to Your App Directory

```bash
cd my-first-app
```

## 4. Start the Development Server

```bash
npm start
```

This will open your React app in the browser at [http://localhost:3000](http://localhost:3000).

## 5. Edit Your App

Open the project folder in your code editor and start editing files in the `src` directory.

---

**Summary of Commands:**

```bash
npx create-react-app my-first-app
cd my-first-app
npm start
```

You're now ready to build with React!
